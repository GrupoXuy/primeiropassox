# Primeiro Passo X — projeto para Arena

Este pacote contém um protótipo front-end responsivo da presença institucional da Primeiro Passo X.

## Conteúdo
- `index.html`: site estático responsivo.
- `assets/logo-primeiro-passo-x.jpeg`: logomarca enviada como referência principal.
- `assets/referencia-institucional.jpeg`: flyer de referência de conteúdo/direção visual.

## Como abrir
Abra `index.html` em um navegador ou importe os arquivos para o ambiente Arena mantendo a estrutura:
- index.html
- assets/

## Importante antes de publicar
Este é um protótipo de interface, não um sistema de recrutamento em produção.
- O formulário ainda não envia nem armazena dados.
- Não há painel administrativo.
- Não há autenticação, banco de dados ou integração de e-mail.
- Não existem vagas reais publicadas; a seção informa que as oportunidades estão em atualização.
- Não foram inventados telefone, endereço, e-mail, empregadores, países, salários ou vagas.

## Próximas integrações recomendadas
1. Backend e banco de dados para candidaturas.
2. Consentimento LGPD registrável, política de privacidade e canal para solicitações dos titulares.
3. Validação server-side e proteção contra spam.
4. Autenticação administrativa segura com autorização por função (admin), sem promoção automática.
5. Painel para visualizar, filtrar e atualizar status de candidatos.
6. Gestão de vagas com publicação somente após validação dos dados e condições.
7. HTTPS, backups, logs e controle de acesso.
